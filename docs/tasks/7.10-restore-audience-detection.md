# 7.10 恢复人群包状态检测规则

## 目标

恢复 `ruyi-automation-1.1.9` 使用的人群包检测行为，先排除阶段 7.6 引入的严格 `SUCCESS` 判断对现网“在线”状态的误判。

## 范围

- 修改 `apps/server/src/modules/files/platform.js` 的人群包列表检测；
- 目标名称支持完全匹配或平台名称包含目标名称；
- 只有 `status` 或 `frontStatus` 为 `PROCESSING` 时计入处理中；
- 保留现有分页、接口响应校验和自动推进调用方式；
- 补充或调整纯函数测试，覆盖在线/非 PROCESSING 状态不计入处理中；
- 不修改洞悉结果检测逻辑，不连接远程数据库，不启动浏览器。

## 验收

- `npm run test:all` 通过；
- 平台检测相关测试通过；
- 不读取或修改 `.env`、状态文件、`upload/`、`ruyi-profile/` 数据。
