# 洞悉后自动清理平台人群

## 目标与范围

新整任务在洞悉提交获得平台成功确认、数据库阶段已推进后，自动删除该任务对应的平台人群，释放创建容量。用户无需操作，不新增手动清理按钮。不删除上传文件、洞悉任务或下载结果，不扫删其他任务人群。

## 安全边界

- 使用当前任务用户的登录态；数据库校验任务、用户、双租约和已完成洞悉阶段。
- 精确匹配数据库平台名称；唯一命中才选中，核对选中的平台 ID，禁止模糊匹配、全选或多选删除。
- 平台页面需业务元素持续就绪；搜索结果需确认来自本次搜索，不能将加载中的空列表判成已删除。
- 洞悉未就绪、提交失败、提交不确定或数据库推进失败时不删除。
- 洞悉响应必须 HTTP 成功并有明确成功标记；仅含 `data`、存在非数值零的 `code`/`ret` 或显式失败都不授予删除资格。
- 删除失败不回退洞悉阶段、不重复洞悉提交、不阻断结果下载。后续正常执行轮次可重试清理；已删除视为幂等成功。
- 本次真实试删仅授权 `pzw_oaid_73bd0476_1`，已在本地登录用户 pzw 的平台列表确认 ID `45875460`。不自动清理其他既有任务。
- 不读登录态文件、Profile、`.env` 或人群正文；登录态仅在本地服务内存中复用，不打印、返回或持久化明文。

## 验收

覆盖精确匹配、重复/缺失名称、额外勾选、确认弹窗、接口失败/不确定、停止/租约失效、成功后阶段保留及恢复清理；运行 `npm test`、差异检查。真实操作只试删指定人群并核实搜索无匹配，不据此声称删除后洞悉结果依赖已全面验证。
