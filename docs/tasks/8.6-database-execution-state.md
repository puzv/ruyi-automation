# 整任务执行状态统一入库

目标：网页与 MCP 的整任务使用数据库作为文件映射、四步待办、执行进度和结果归档的唯一事实来源。整任务执行不生成、不读取、不回退到 `file-manifest.json`、创建/分析/下载待办 JSON 或结果 `manifest.json`。

## 范围与约束

- `ruyi_task_files` 保存稳定平台名称、执行相对路径及逐文件阶段；按阶段派生待办，排除项不参与后续执行。
- Worker 与自动化子进程共享数据访问契约；写操作校验用户、任务、子流程及执行租约，数据库异常立即停止，禁止降级到磁盘清单。
- 原始文件、执行副本、下载文件和日志继续放在磁盘；文件内容不入数据库。
- 结果索引通过新增迁移保留每轮下载的封存快照，部分下载在重试/中断继续时可合并至最终结果包；API、MCP 和 ZIP 使用相同数据库索引。
- 旧独立脚本的历史兼容逻辑可保留，但有整任务上下文时不得进入旧 JSON 路径。已有清单不直接删除。旧任务若缺少可靠数据库状态，必须明确拒绝或通过显式迁移处理，不猜测后重复提交。
- 不修改已有迁移，不连接远程库，不变更测试库结构，不读取实际人群文件或登录态；新增迁移的应用与验证仅限本机开发库。

## 验收

1. 使用临时文件、伪造平台和数据库仓储完成 upload/create/analyse/download，执行目录无流程 JSON 或结果索引 JSON。
2. 数据库阶段推进即时持久化，未就绪保留阶段；同任务轮询不重复上传，重启继续跳过已完成文件。
3. 多任务同名、跨用户、租约失效、停止/恢复、排除文件和数据库失败路径均受保护。
4. 结果文件先安全落盘再登记；封存后不可追加，数据库索引失效不能回退目录扫描或 JSON；部分结果重试合并、ZIP 下载及权限验证通过。
5. 完成专项测试、`npm test`、前端构建及差异检查。真实平台调用不在自动验收中执行。
# 历史下载结果索引补建

部署新增结果表之后，旧整任务下载结果需要显式补建索引；运行时不会回退读取 JSON。
`scripts/backfill-task-results.js` 仅允许本机 `127.0.0.1:3306`、账号 `ruyi`、库 `ruyi_dev`，不加载 `.env`。
使用显式环境变量，先预览，再根据预览结果决定是否执行：

```sh
RUYI_DB_HOST=127.0.0.1 RUYI_DB_PORT=3306 RUYI_DB_USER=ruyi RUYI_DB_PASSWORD=ruyi RUYI_DB_NAME=ruyi_dev node scripts/backfill-task-results.js --task-id <完整任务UUID>
RUYI_DB_HOST=127.0.0.1 RUYI_DB_PORT=3306 RUYI_DB_USER=ruyi RUYI_DB_PASSWORD=ruyi RUYI_DB_NAME=ruyi_dev node scripts/backfill-task-results.js --task-id <完整任务UUID> --apply
```

默认 dry-run 不写库。脚本只查询所属任务、文件和终态下载执行记录，列出结果目录并检查文件元数据，不读取 JSON 或结果正文，不修改原文件。
只接受能与初始文件主干唯一关联的非空 XLSX、XLS、CSV 文件；未知格式、符号链接、歧义映射会拒绝。
已存在数据库索引的下载轮次保持原样；缺失历史成功结果目录会拒绝。事务锁定任务与执行记录后整体插入封存结果集，失败不部分提交。
