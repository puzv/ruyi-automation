# 7.3 移除桌面登录与调试模式

## 背景与依据

- 7.0–7.2 实现的扫码登录已通过本机真实扫码验收（QQ）。
- 2026-11-03，Claude 用现有生产镜像（`linux/amd64`、`pwuser`、**不启动 Xvfb，`DISPLAY` 为空**）跑了真实 `sessions.js`，并由用户用 QQ 扫码，全流程成功：
  - 微信二维码显示 → 切换 QQ → 已扫码 → 如翼登录 → DataNexus 自动点击登录 → 两站复查 → 保存，共约 30 秒；
  - 峰值内存 1.2GB，K8s 限制为 4Gi。
- 用户确认：可以接受没有后备登录方式；同时去掉操作面板的「调试模式」开关（K8s 上没有桌面后，该开关会导致任务启动失败）。本机开发需要看到浏览器时，用环境变量 `RUYI_HEADLESS=0`。

## 范围

### 1. 服务端：只保留扫码登录
- `platform-login/sessions.js`：
  - 删除 `mode` / `desktop` 分支、`display` 字段、`readDisplayConfig` 的使用，以及“桌面占用”互斥。
  - 浏览器始终 `headless: true`。
  - `startSession` 不再接受 `mode`，只接受 `method`。
  - 并发上限仍为 `RUYI_MAX_LOGIN_SESSIONS`（默认 2）。
  - `publicSession` 去掉 `display` 和 `mode`。
  - 删除只服务于桌面模式的 `waitForLogin`（人工登录轮询）。如翼和 DataNexus 都走 `qr.js`。
- 删除 `platform-login/display.js`、`platform-login/vnc-proxy.js`。从 `routes.js`、`app.js`、`state-routes.js` 中移除相关注册和 `display` 字段。
- `POST /api/platform-login`：请求体只读 `method`。传入 `mode` 时忽略，不报错，兼容尚未刷新的旧前端页面。
- 审计 `detail` 去掉 `mode`，保留 `method`。

### 2. 服务端：去掉运行模式切换
- 删除 `GET/POST /api/runtime-mode`，以及 `state.headlessMode`。
- 任务（`files/routes.js` 入队、`auto-advance/engine.js` 入队、`jobs/memory.js`）和平台检查（`files/platform.js`）统一使用 `@ruyi/shared/config` 的 `browserHeadless`，它由 `RUYI_HEADLESS` 决定，默认 true。
- `ruyi_jobs.headless` 列保留，不改迁移，写入 `browserHeadless` 即可。
- 令牌白名单不涉及这两个接口。`audit/actions.js` 删除 `/api/runtime-mode` 分支。
- `labels.js` 中 `runtime.mode_change` 的中文名**保留**，历史操作记录还要显示。

### 3. 前端
- `PlatformLoginView.vue`：删除「改用远程桌面 / 本机窗口登录」入口、`desktopLabel`、`RemoteDesktop` 的使用和 `local` 提示文字。`risk` 状态的提示改为「登录环境异常，请稍后重新扫码」。
- 删除 `apps/web/src/components/RemoteDesktop.vue`。从 `apps/web/package.json` 移除 `@novnc/novnc` 依赖，并在根目录运行 `npm install` 更新 lockfile。**这一步由 Claude 在沙箱外执行，你只改 package.json，不要运行 npm install。**
- `WorkbenchView.vue`：删除顶栏「调试模式 / 后台模式」开关及相关状态、请求和样式。

### 4. 部署
- `deploy/Dockerfile.workspace`：
  - 删除 `RUYI_LOGIN_DISPLAY`、`DISPLAY` 环境变量。
  - apt 不再安装 `xvfb x11-utils openbox x11vnc`。如果没有其他包需要安装，删除整个 apt 步骤，包括切换软件源的部分。
  - 删除 `chmod start-desktop.sh`。
  - `ENTRYPOINT` 改为 `["npm", "start"]`。
  - 保留 `pwuser`、`EXPOSE 5173`、`RUYI_HEADLESS=1`。
- 删除 `deploy/scripts/start-desktop.sh` 和 `deploy/Dockerfile.desktop`。`deploy/scripts/build-context.js` 不再复制 `start-desktop.sh`。
- 旧布局的 `deploy/Dockerfile`：只用于构建旧 Git 引用，**保持不变**。如果 `build-context.js` 为旧布局复制 `start-desktop.sh`，那么只在旧布局时复制。实现时先判断旧布局是否依赖它，并在总结中说明。
- `deploy/k8s/ruyi-upload-dashboard.yaml`：删除 `RUYI_LOGIN_DISPLAY`、`DISPLAY`。`/dev/shm` 挂载保留，无头 Chromium 仍需要。`terminationGracePeriodSeconds` 保持不变。
- `deploy/test/container-preparation.test.js`：更新新布局 Dockerfile 的断言，删除对 `start-desktop.sh` 的桌面监督测试。如果旧布局仍需要该脚本，旧布局部分保留。
- 文档：
  - `deploy/DESKTOP.md` 删除，或改写为一段“已移除，平台登录改为网页扫码”的说明，二选一，倾向删除；
  - `deploy/README.md` 中关于桌面的段落同步更新；
  - 仓库根 `README.md` 若提到远程桌面或调试模式，同步修改。

### 5. 测试
- 删除 `test/vnc-proxy.test.js`，并从 `package.json` 的 `test:all` 中移除 `test:vnc-proxy`。
- 更新 `test/platform-login.test.js`、`test/platform-login-routes.test.js`、`test/frontend-platform-login.test.js`：
  - 删除 desktop / vnc / local 场景；
  - 保留并补充：并发上限、跨用户隔离、`mode` 参数被忽略、`publicSession` 不含 `display` 和 `mode`。
- 更新所有调用 `/api/runtime-mode` 的测试（`server-routes`、`server-audit`、`server-auth`、`server-registration`、`api-tokens`、`api-tokens-guard`、`worker` 等），删除相关断言，或改为断言该接口返回 404。
- 新增断言：任务入队时 `headless` 等于 `browserHeadless`。
- `grep -rn "RemoteDesktop\|vnc\|novnc\|RUYI_LOGIN_DISPLAY\|runtime-mode\|headlessMode\|start-desktop" apps packages test deploy scripts README.md` 应只剩 `labels.js` 中历史动作的中文名，以及旧布局确实需要的部分；在总结中列出剩余项及原因。

## 不要做
- 不改迁移，不新增依赖，不运行 npm install。
- 不改 `qr.js` 的扫码逻辑，只删除 desktop 分支和对 `display` 的引用。
- 不读 `.env`、`state-test.json`、`upload/`、`ruyi-profile/`。

`npm test` 通过（沙箱阻塞浏览器/数据库测试时请说明，Claude 会在沙箱外复验）；`node deploy/test/container-preparation.test.js` 通过。最后用中文列出改动和删除的文件、验证方式、未完成或不确定之处。
