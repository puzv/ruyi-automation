# 连续等待记录展示聚合

任务流程与操作记录中的相邻等待检查，只有用户、任务编号、步骤、等待类别一致时才合并展示。等待平台处理和等待登录分组独立；失败、取消、中断、不同用户/任务/步骤均打断分组。缺少可靠任务编号的历史操作记录不猜测合并。

保留全部底层记录；分组显示次数、首次和最近时间，可展开每次流程日志或原始操作明细。操作记录先跨原始页边界合并，再按展示条目分页，总数代表展示条目数，`rawTotal` 单独保留原始记录数。后端按主键分批扫描，不把全量日志装入内存；展开分组通过 `groupId` 按 20 条分页加载全部原始明细。`snapshot` 固定浏览范围，避免新增记录导致翻页漂移。管理员复用相同组件和逻辑，筛选隐藏的真实异常仍打断等待分组。

验证：`node test/frontend-jobs.test.js` 包含纯函数边界和组件行为测试，`node test/frontend-labels.test.js` 包含等待登录文案测试。`node test/task-ui-browser-smoke.test.js` 检查流程连续等待日志与用户/管理员操作记录展开、等待类别和真实失败展示。
