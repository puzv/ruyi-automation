# 6.4 修复内置桌面的 WebSocket 子协议

## 问题
线上登录流程可创建，但内置桌面一直断开。当前 noVNC 的 wsProtocols 默认是空数组，RemoteDesktop 未显式传入；服务端要求 binary 子协议并拒绝缺失者（403）。

## 范围
- 仅修改 web/src/components/RemoteDesktop.vue，显式声明 binary 子协议。
- 在现有 test/frontend-platform-login.test.js 中补充可执行回归测试，实际执行组件连接逻辑并检查 RFB 收到的参数，避免仅字符串匹配。
- 不放宽服务端同源、用户归属、Cookie 或子协议检查；不引入依赖，不改数据库、部署和其他功能。
- 子代理不能启动 Chromium；主代理负责浏览器验证、构建与完整回归。

## 验收
- 前端实际构造的连接声明 binary，保留同源 ws/wss 和会话路径。
- 无子协议连接仍被服务端拒绝。
- 主代理检查变更范围，运行 npm run test:all、构建前端并补测连接参数和浏览器握手。
- 不读取敏感文件和 upload 数据；仅主代理 shasum 比较 .env 和 state-test.json。
- 本地修复验收后沿用用户此前的镜像推送授权，构建并推送新的修复标签，不覆盖旧标签；线上 Deployment 仍由用户在 Dashboard 手动更新，本任务不直接操作集群。
