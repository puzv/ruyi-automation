# 7.9 调整自动推进模块位置

## 目标

将自动推进模块从当前状态区域中移出，独立放置在快捷操作与当前状态之间。

## 范围

- 仅调整 `WorkbenchView.vue` 的页面结构和必要的前端测试。
- 保留自动推进的状态、开关、进度展示和轮询逻辑，不改变 API 或任务行为。
- 保持现有快捷操作、当前状态和自动推进样式可用。

## 验证

- 验证页面模板顺序为快捷操作、自动推进、当前状态。
- 运行 `node test/frontend-jobs.test.js`、`npm test`、`npm run build:web` 和 `git diff --check`。
- 不读取敏感数据，不启动 Chromium，不提交或推送。
