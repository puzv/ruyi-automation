# 任务改造重新验收

用户指出任务页面仍显示“接口不存在”，此前仅构建和测试通过不能代表运行中的服务已更新。本轮重新审核任务从创建、排队、执行到页面展示的完整链路，不增加表结构。

## 验收范围

- 通过真实 buildApp 注册 /api/tasks，真实会话鉴权下列表能返回，未登录 401，普通用户访问管理接口 403。
- 创建任务必须先完成平台登录，一次初始上传，默认名称为任务编号，无草稿和补传入口。
- 任务独立文件目录；任务清单保留初始文件名，未开始任务可排除文件，最后一个文件删除后取消。
- 文件排除和删除任务使用任务行锁，与 Worker 认领互斥；任务版本失败时事务不得提交部分文件修改。
- 同用户 FIFO 且同时一任务，平台并发统计不能重复计算整任务及其步骤记录。
- 平台登录失效仅允许当前租约触发，统一等待登录；重新登录后必须明确恢复，恢复接口再次验证登录态并保留原顺序。
- 自动推进 upload/create/analyse/download，异步处理时保持运行中；失败、取消和中断不阻塞后续任务。
- 运行任务删除先请求取消，待停止后可删除；删除仅为软删除，不删除数据文件或平台资源。
- 新任务脚本、日志、结果归档使用 tasks/<id>/execution；原始上传保留在任务根的 raw。
- 我的任务及管理员全部任务使用聚合任务接口，任务一行，支持进度、展开日志/文件、状态反馈及结束后的结果下载。
- 删除操作需确认，加载失败不能伪装成“暂无任务”，创建采用按钮和弹窗。
- 启动实际前后端后验证浏览器页面和代理接口；不能用预览模式替代正常服务。

## 后端补充测试

- `node test/task-app-routes.test.js`：真实应用注册、会话、管理员隔离、恢复前登录检查。
- `node test/task-mutation-safety.test.js`：文件排除事务回滚、行锁、最后文件取消、任务日志路径。
- `node test/task-login-wait.test.js`：失效租约保护、用户队列冻结与恢复。

真实如翼平台操作涉及用户文件和外部服务，本轮不自动提交真实人群包；本地合成数据测试不能声称已经验证平台真实处理耗时及返回结果。

## 可复现浏览器界面检查

先启动正常 Vite 前端（默认 `http://localhost:5173`），从仓库根运行：

```sh
node test/task-ui-browser-smoke.test.js
```

该脚本使用全新浏览器上下文，以内存合成任务和文件拦截全部 `/api/` 请求；拦截外部网络请求，不读取真实 Cookie、storageState 或上传数据。它验证桌面任务列表、原始文件详情、流程日志、创建任务原生弹窗、登录门禁、管理员只读，以及 390px 手机布局无页面横向溢出、弹窗可选文件并可关闭。这是前端界面验证，不代表真实平台任务已跑通。

可选环境变量：`RUYI_UI_SMOKE_URL`（仅本机地址）、`RUYI_UI_SMOKE_BROWSER`（Chrome/Chromium 可执行文件路径）、`RUYI_UI_SMOKE_SCREENSHOTS`（截图目录，默认 `os.tmpdir()`）。默认探测系统 Chrome/Chromium，找不到时使用已安装的 Playwright Chromium；不自动安装浏览器。生成 `task-ui-list.png`、`task-ui-create.png`、`task-ui-admin.png`、`task-ui-mobile-list.png`、`task-ui-mobile-create.png`。

此检查需要浏览器和前端开发服务，因此不加入默认 `npm test`。
