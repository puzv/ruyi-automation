# 创建任务支持选择文件夹

本次仅扩展创建任务弹窗的初始文件选择，不改后端接口、表结构或执行队列，不提供补传。

- 保留多选文件入口，新增包含子目录的文件夹选择。
- 只按 File 元数据筛选，不读取内容；隐藏路径段和非 pn/idfa/oaid 的 txt/csv 文件跳过。
- 显示有效数、跳过数与原始相对路径；multipart 只上传 basename。
- NFC 同名或结果主名称重复、超过 1000 个有效文件、总大小超过 1GB 时阻止提交并提示。
- 取消选择保留原清单，换选替换清单，两种入口都受平台登录门禁保护。

验证：`node test/frontend-jobs.test.js` 覆盖筛选、冲突、数量/大小、取消和上传文件名；`node test/task-ui-browser-smoke.test.js` 使用临时合成目录（含子目录和隐藏目录）实际选择文件夹，验证清单、重复选择并输出 `task-ui-folder.png`。临时合成数据保留，不接触真实文件。
