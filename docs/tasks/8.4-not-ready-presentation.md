# 平台处理中暂未就绪的业务展示

仅针对带 task_id 的聚合任务流程记录：status=failed、exit_code=2、无退出信号且登录态未过期时，聚合任务用户/管理员详情接口展示 waiting_platform（等待平台处理），保留退出码，清除业务错误提示。真实失败、取消、中断、登录态失效、历史独立执行记录保持原语义。

Worker 不改存储枚举或退出码，不伪造流程成功，继续按既有 NOT_READY 自动重试。新的检查审计标记正常检查结束并带 outcome=not_ready/status=waiting_platform；前端显示“等待平台处理”，而非“成功”或“失败”。旧聚合 API 尚未重启时，前端仅识别错误提示固定前缀“任务未就绪，稍后可重试”，待空闲后重启后端启用显式状态。

验证：`node test/task-job-presentation.test.js`、`node test/task-app-routes.test.js`、`node test/frontend-jobs.test.js`、`node test/frontend-labels.test.js`、`node test/task-worker-lifecycle.test.js`。浏览器独立检查由 `node test/task-ui-browser-smoke.test.js` 覆盖等待检查后成功及真实失败展示。
