# 未登录平台时拒绝导入文件

范围：仅修复用户未登录平台时，文件先导入、随后上传启动失败而遗留原始文件的问题；不修改重名规则、排队互斥、已有残留文件或失败续传功能。

- 认证模式的网页导入和传输票据导入共用平台登录态校验，复用启动任务时的 `loadUserState`，不额外发起平台请求。
- 接收 multipart 文件流前校验，文件落盘前再次校验。无登录态、状态标记失效或登录态无法解密时，返回 HTTP 409 / `PLATFORM_LOGIN_REQUIRED`，不创建导入目录或写入文件。
- 网页显示登录提示与已有“前往平台登录”入口，不继续提交上传任务。
- 一次性上传票据仍在请求到达时领用，拒绝后提示登录并重新获取链接。
- 保留无认证模式兼容性。校验基于后端保存的状态，不保证检测到尚未被平台验证发现的远端会话失效；接收完成后校验与后续任务启动也不是原子事务。

验证：`npm test`、`npm run test:mcp-transfer`、前端构建；使用伪造 storageState、临时目录和本机 `ruyi_test` 数据库，不读取真实上传数据或登录态。
