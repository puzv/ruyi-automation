## 背景
`test/server-routes.test.js` 已覆盖主要路径。审查时手工验证了以下行为，需要固化成自动测试，防止后续阶段改坏。

## 新增测试（追加到 `test/server-routes.test.js`，或新建 `test/server-edge.test.js` 并加入 `npm test`）
同样使用临时 `RUYI_UPLOAD_DIR` 和 `app.inject()`，不启动浏览器、不访问外网、不启动真实任务脚本。

1. **路径穿越**：上传文件名为 `../../etc/evil_idfa.txt` 的文件，返回 `{ ok: true, count: 1 }`，文件只出现在 `raw/evil_idfa.txt`，临时目录之外没有生成文件。
2. **文件夹上传的相对路径**：文件名 `sub/dir/z_oaid.csv`，保存为 `raw/z_oaid.csv`。
3. **中文文件名乱码修复**：模拟浏览器把 UTF-8 文件名按 latin1 传入的情况（`Buffer.from('测试_pn.txt', 'utf8').toString('latin1')` 作为 multipart 的 filename），保存后的文件名为 `测试_pn.txt`。
4. **不导入的文件**：`.hidden_idfa.txt`、`a_idfa.xlsx`、`readme.txt`（不含 idfa/oaid/pn）都计入 `skipped`，不写入 `raw/`。
5. **非 multipart 请求**：`POST /api/import-folder` 发送 JSON，返回 `{ ok: true, count: 0, skipped: 0 }`（与原实现一致）。
6. **JSON 体积上限**：向 `POST /api/runtime-mode` 发送 3MB 的 JSON，返回 413 且 `ok === false`；发送 1MB 以内的合法 JSON 正常处理。
7. **未知 API 不被页面回退接管**：在构建了 `index.html` 的 `webDist` 下，`GET /api/nope`、`POST /api/nope` 均返回 404 JSON，而 `GET /nope` 返回 index.html。
8. **运行任务的互斥**：分别把共享状态的 `profileReleaseRunning`、`profileProbeRunning`、`loginFlow`（任意对象）置为真值，`POST /api/run/upload` 各自返回 409 和原中文提示；每个用例结束后还原状态。
9. **任务查询**：在共享状态 `jobs` 中放入 `{ id: 't1', task: 'upload', running: false, output: 'hello', code: 0 }`，`GET /api/jobs/t1` 返回该对象，且响应中**不包含** `child` 字段（若放入时用 `Object.defineProperty` 定义不可枚举的 `child`）。
