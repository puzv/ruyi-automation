# 7.0 扫码登录（网页直接显示二维码）

## 背景

当前平台登录要打开一个有界面的浏览器：本机部署弹出 Chromium 窗口，K8s 部署要通过远程桌面（noVNC）操作。用户希望直接在平台网页上显示登录二维码，扫码后其余步骤由服务器自动完成。

Claude 已在 2026-11-02 用无头 Chromium 做过实验，**QQ 扫码全流程跑通**（实验脚本：`/tmp/mcp-spike/qr-exp.js`，仅供参考，不进仓库）。微信流程与 QQ 一致，暂不单独实测。

### 实验观察到的页面结构（实现依据）

1. 打开 `loginTargets.ruyi.url` 后，跳转到 `sso.e.qq.com/login/hub`（腾讯营销统一登录页）。无头模式下二维码可正常渲染，也没有触发风控。
2. 登录卡片有两个标签：「微信账号登录」（默认）和「QQ账号登录」，`page.getByText('QQ账号登录', { exact: true })` 可以切换。
   - 微信：二维码在 `iframe[src*="open.weixin.qq.com/connect/qrconnect"]` 中。
   - QQ：二维码在 `xui.ptlogin2.qq.com` 的 frame 中，元素 `#qrlogin_img`。其状态元素：
     - `#qr_invalid` 可见 = 二维码已失效，点击 `#qr_invalid` / `#qr_area` 刷新。**约 2 分钟失效一次**，必须自动刷新。
     - `#qrlogin_step2` 可见 = 已扫码，等待手机确认。
     - `#qrlogin_step3` 可见 = 已确认，正在登录。
     - `#qlogin_tips_2` 可见 = 登录环境异常。
3. 扫码确认后跳转顺序为 `ruyi.qq.com/auth` → `ruyi.qq.com/insight/create`，之后用现有的 `pageLooksLoggedIn` 检查（连续稳定 3 秒）即可通过。
4. 接着打开 `loginTargets.datanexus.url`，会被重定向到 `datanexus.qq.com/`，此时还没登录。页面顶部有 `button.spaui-button.spaui-button-primary`，文字为「登录」，位于页面头部右侧，父元素在 header 中。**点击它后不需要再扫码**（复用统一登录），页面跳到 `datanexus.qq.com/web/datasource`，再打开目标地址就能通过检查。
5. 两个站点用现有的 `probeSite` 复查都通过。

## 目标

平台登录页默认使用**扫码登录**：网页直接显示二维码，支持微信 / QQ 切换。用户扫码确认后，服务器自动完成如翼和 DataNexus 两个站点的登录、复查并加密保存登录态。现有远程桌面 / 本机窗口方式保留为后备入口。

## 范围

### 1. 服务端：扫码登录会话（扩展 `apps/server/src/modules/platform-login/sessions.js`）

- `startSession` 新增 `mode` 参数：`'qr'`（默认）或 `'desktop'`（即现在的行为，按 `RUYI_LOGIN_DISPLAY` 选 vnc / local）。`POST /api/platform-login` 从请求体读取 `{ mode, method }`，`method` 为 `'wechat' | 'qq'`，默认 `'wechat'`。
- `qr` 模式：
  - 以 **headless** 启动浏览器（`headless: true`，沿用 `chromePath`、`--disable-dev-shm-usage`）。不占用 VNC 桌面，因此**不受“同时只能一人使用桌面”的限制**，并发数沿用 `RUYI_MAX_LOGIN_SESSIONS`（默认 2）。
  - 打开如翼目标地址，到达登录页后按 `method` 切换标签。
  - 维护 `session.qr`：`{ method, state, image, updatedAt }`。
    - `state` ∈ `waiting`（等待扫码）、`scanned`（已扫码待确认）、`confirmed`（已确认正在登录）、`expired`（失效刷新中）、`risk`（环境异常）。
    - 微信只需区分“仍在登录页”和“已离开登录页”。
  - `image` 为二维码区域截图（PNG Buffer）：
    - 微信截 iframe 元素；QQ 截 `#qrlogin_img` 所在区域，或包含它的二维码容器。
    - **只截二维码区域，不截整页**，避免把其他页面内容传给前端。
    - 每 1.5–2 秒刷新一次，离开登录页后清空。
  - QQ 二维码失效时自动点击刷新。微信二维码失效时（iframe 内出现过期或刷新提示），重新加载登录页并切回微信。两者都记录失效次数，超过 5 次后以 `expired` 结束会话，提示“二维码多次过期，请重新开始”。
  - 如翼登录判定沿用现有逻辑（`pageLooksLoggedIn` 连续 3 次）。
  - DataNexus：打开目标地址，如果没有直接登录，查找**页面头部**文字为「登录」的按钮并点击。可见、`getBoundingClientRect().y < 120`、文字精确匹配，优先 `button`。点击后等待登录判定。若 30 秒内仍未登录，再打开一次目标地址判定；仍失败则 `failed`，提示“DataNexus 自动登录失败，请改用远程桌面登录”。
  - 两站复查（`probeSite`）、加密保存、审计都沿用现有流程，`detail` 中增加 `mode: 'qr'` 和 `method`。
  - `session.message` 按阶段更新为中文，例如“请使用微信扫描二维码”“已扫码，请在手机上确认”“如翼已登录，正在登录 DataNexus”“正在保存平台登录态”。
- `publicSession` 增加 `mode`，以及 `qr: { method, state, updatedAt }`，**不包含图片**。
- 新增 `GET /api/platform-login/:id/qr.png`：只允许会话所属用户访问，并加 `Cache-Control: no-store`。会话不在等待扫码阶段或没有图片时返回 404。
- 新增 `POST /api/platform-login/:id/method`，body `{ method }`：在等待扫码阶段切换微信 / QQ，其他阶段返回 409。
- 安全要求：
  - 截图和登录态只在内存中，会话结束即释放。
  - 不得把截图、URL 查询参数（含 OAuth code）写入日志或审计。
  - 日志中的 URL 只允许 host + path。
- 令牌（API Token）白名单**不加入**这些接口：扫码登录只能由本人在网页上完成。

### 2. 前端：`apps/web/src/views/PlatformLoginView.vue`

- 默认按钮「扫码登录」，旁边小字链接「改用远程桌面登录」（K8s）或「改用本机窗口登录」（本机），对应 `mode: 'desktop'`，也就是现有流程和 `RemoteDesktop` 组件。
- 扫码会话进行中时：
  - 显示「微信 / QQ」切换（调用切换接口），以及二维码图片 `<img :src="/api/platform-login/<id>/qr.png?t=<updatedAt>">`。轮询沿用现有 1.5 秒间隔，`qr.updatedAt` 变化时更新 `src`。
  - 按 `qr.state` 显示提示：等待扫码 /「已扫码，请在手机上确认」/「正在登录…」/「二维码已过期，正在刷新」/「登录环境异常，请改用远程桌面登录」。
  - 二维码区域在“已扫码”和“正在登录”时加半透明遮罩，避免重复扫码。
  - 离开登录页后（`qr` 为空）显示站点进度（复用现有如翼 / DataNexus 徽标）。
  - 保留取消按钮和剩余时间。
- 成功、失败、取消后的行为保持不变。
- 文案中文，样式沿用现有页面。

### 3. 测试

- `test/platform-login.test.js`（数据库测试）：沿用现有假浏览器（`launch` / `checks` 注入），**不得启动真实浏览器**。新增假页面对象，模拟以下场景：
  - 登录页 → 切换 QQ → 截图 → 二维码失效 → 自动刷新 → 扫码 → 如翼登录 → DataNexus 需点击登录 → 成功保存；
  - DataNexus 点击后仍未登录 → `failed`；
  - 失效超过 5 次 → `expired`；
  - 切换 method 接口在各阶段的行为；
  - `qr.png` 跨用户访问返回 404，非等待阶段返回 404；
  - 审计 `detail` 不含 URL 查询参数或图片。

  需要时可以把截图、点击等页面操作抽成可注入的函数，便于用假对象测试。
- `test/frontend-platform-login.test.js`：默认显示扫码按钮；会话进行中显示二维码和切换按钮；状态提示正确；「改用远程桌面登录」发起 `mode: 'desktop'`。

## 不要做

- 不读 `.env`、`state-test.json`、`upload/`、`ruyi-profile/`。
