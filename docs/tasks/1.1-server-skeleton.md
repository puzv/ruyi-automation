# 任务 1.1：搭建独立后端骨架

先阅读 `AGENTS.md` 和 `docs/REFACTOR_PLAN.md`。本任务只搭骨架，**不迁移任何现有接口**，不修改 `web/vite.config.js`。

## 背景
现在所有 API 写在 `web/vite.config.js` 的 Vite 插件里（Express），只能跑在 Vite 开发服务器中。
阶段 1 要把它拆成独立的 Fastify 服务。本任务先搭出能启动、能提供前端页面的空服务。

## 要做的事
1. 新建 `server/app.js`，导出 `buildApp(options)`，返回一个**尚未 listen** 的 Fastify 实例：
   - `options.webDist`：前端构建目录，默认项目根目录下的 `web/dist`
   - `options.logger`：传给 Fastify，默认 `true`
   - 注册 `GET /api/health`，返回 `{ ok: true }`
   - 用 `@fastify/static` 提供 `webDist` 下的静态文件
   - 非 `/api/` 开头、且找不到静态文件的 GET 请求返回 `index.html`（单页应用回退）
   - `/api/` 开头但未注册的路径返回 404 JSON：`{ ok: false, message: '接口不存在' }`
   - `webDist` 不存在或没有 `index.html` 时，服务仍能启动，`/api/health` 正常；页面请求返回 503 JSON，提示先执行前端构建
2. 新建 `server/index.js`：调用 `buildApp()` 并监听
   - 端口读 `RUYI_SERVER_PORT`，默认 `5173`（与现有部署端口一致）；地址读 `RUYI_SERVER_HOST`，默认 `0.0.0.0`
   - 收到 `SIGTERM` / `SIGINT` 时调用 `app.close()` 后退出
3. 在根目录 `package.json` 的 `scripts` 中新增：
   - `"start": "node server/index.js"`
   - `"build:web": "npm --prefix web run build"`
4. 新增 `test/server-app.test.js`，使用 `app.inject()`（不真正监听端口）验证：
   - `/api/health` 返回 200 和 `{ ok: true }`
   - 未注册的 `/api/xxx` 返回 404 且 `ok === false`
   - 准备一个临时目录作为 `webDist`，放入 `index.html` 和 `assets/a.js`：`/` 和 `/some/page` 返回 index.html 内容，`/assets/a.js` 返回该文件
   - `webDist` 指向不存在的目录时，`/api/health` 仍为 200，`/` 返回 503
   - 测试结束删除临时目录、调用 `app.close()`
5. 把 `node test/server-app.test.js` 追加到根 `package.json` 的 `test` 脚本末尾（用 `&&` 连接，保留原有内容）。

## 约束
- 依赖 `fastify@5`、`@fastify/static@8`、`@fastify/multipart@9` 已安装在根目录，**不要再安装或升级任何包**。本任务不需要 multipart。
- CommonJS，代码风格与现有 `lib/`、`scripts/` 一致；面向用户的消息用中文。
- 不修改 `web/` 下任何文件。

## 完成标准
- `npm test` 全部通过。
- `npm run build:web && npm start` 后，浏览器打开 http://127.0.0.1:5173 能看到现有页面（页面上的接口此时会 404，这是预期的）。你无需实际启动常驻服务，测试覆盖即可。
- 最后用中文列出：新增/修改的文件、验证方法、任何不确定之处。
