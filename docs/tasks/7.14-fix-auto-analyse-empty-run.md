# 7.14 修复自动洞悉空跑

## 目标

统一工作区状态与 `analyseAll.js` 对分析待办的判定，避免分析清单中已完成项目导致自动推进提交一个约 1 秒成功但没有实际操作的空任务。

## 范围

- 工作区状态统计分析清单时排除已写入 `done.json` 的项目，并按不含扩展名的任务名比较。
- 分析批处理脚本使用同样的规范化规则判断已完成项目。
- 增加回归测试，覆盖清单与完成清单重复时的状态和批处理结果。

## 验收

- 自动推进不会为已完成分析项目重复入队。
- 真实待洞悉项目仍会正常入队。
- 运行 `npm test` 和 `npm run test:all`。
