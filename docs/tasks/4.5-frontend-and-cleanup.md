# 任务 4.5：前端平台登录改造，清理 Profile 代码

先阅读 `AGENTS.md`、`docs/REFACTOR_PLAN.md` 的“阶段 4 的具体决定”、4.1～4.4 完成的接口：`server/routes/platform-state.js`、`server/routes/platform-login.js`、`server/platform-login/`（`publicSession` 的字段，含 `display`）、`web/src/components/RemoteDesktop.vue`，以及 `web/src/views/WorkbenchView.vue`、`web/src/App.vue`、`web/src/api.js`、`web/src/labels.js`。

## 目标
1. 用户在网页内完成平台登录：侧边栏显示平台登录状态，点击进入“平台登录”页面，开始登录后在页面内看到远程桌面（vnc 模式）或提示去本机浏览器窗口操作（local 模式），完成后自动返回。
2. 删除所有基于共享 Profile 的登录/释放代码。认证模式已经完全不使用 Profile。

## 一、前端

### 1. 新页面 `web/src/views/PlatformLoginView.vue`（路由 `#/platform-login`，所有登录用户可访问；在 `App.vue` 的路由表中加入）
- 顶部：当前登录态概要（来自 `GET /api/platform-state`）：状态（未登录 / 有效 / 已过期）、登录时间、最近刷新时间、预计过期时间（`expiresHintAt`，显示“约 X 小时后过期”，小于 6 小时用醒目颜色）。时间格式复用 `labels.js` 的 `formatTime`。
- 按钮：
  - “开始登录”（状态为未登录、已过期，或用户主动重新登录时）→ `POST /api/platform-login`，拿到会话后每 1.5 秒轮询 `GET /api/platform-login/:id`
  - “清除登录态”（有效时）→ `window.confirm` 二次确认后 `POST /api/platform-state/clear`
- 登录进行中：
  - 显示两个站点的进度：如翼、DataNexus，各自“等待登录 / 已登录”
  - 显示会话 `message`、剩余时间（按 `expiresAt` 倒计时）
  - `display === 'vnc'`：嵌入 `<RemoteDesktop :session-id="id" />`，区域宽度占满内容区，高宽比 1280:800
  - `display === 'local'`：显示提示“登录窗口已在服务器所在电脑上打开，请在该窗口中完成扫码登录”
  - “取消登录”按钮 → `DELETE /api/platform-login/:id`
- 会话结束：`succeeded` 显示成功并在 2 秒后刷新概要；`failed`/`expired`/`cancelled` 显示 `message` 和“重新开始”按钮
- 收到 409（例如其他人正在登录）时显示服务端 `message`
- 页面卸载时停止轮询（不自动取消登录会话，用户可能只是切换页面；回到本页时，如有进行中的会话应继续显示——用 `sessionStorage` 保存当前会话 ID）

### 2. 侧边栏（`WorkbenchView.vue`）
- 原“平台已登录 / 需要登录”按钮改为读取 `GET /api/platform-state`：
  - `valid` → “平台已登录”（绿色），title 显示预计过期时间
  - `expired` → “平台登录已过期”
  - `none` → “需要平台登录”
  - 点击跳转 `#/platform-login`
- 侧边栏导航增加“平台登录”项（`#/platform-login`）
- 页面加载时以及每次任务结束后刷新一次平台状态；**不再轮询** `/api/login-status`
- 删除：“释放 Profile”按钮、`forceReleaseProfile`、`openLoginPages`、`startLoginPolling`/`stopLoginPolling`、`refreshLoginStatus` 及相关 ref
- 运行任务收到 `code === 'PLATFORM_LOGIN_REQUIRED'` 时：提示“请先完成平台登录”，并提供跳转到 `#/platform-login` 的链接
- 其他工作台功能（操作卡片、状态面板、运行模式切换、任务日志）保持不变

### 3. 标签
`labels.js` 已有的 `platform.login_open`、`profile.release` 保留（历史记录需要显示）。
