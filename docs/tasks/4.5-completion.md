2. 同文件：删除旧登录探测标志阻止 `/api/login-status`、`/api/platform-status`、`/api/login-open` 的三组 409 断言。未认证模式登录状态改验 404，平台检查改验已有任务时返回 409 及规定提示，旧登录入口改验 404。
3. 同文件：删除释放、探测、登录流程三种旧状态分别阻止任务启动的断言。保留已有任务阻止启动的断言，并新增已有任务阻止平台检查的断言。
4. 同文件：删除关闭上下文后 `loginContexts.size === 0` 的断言，因为该集合已移除；保留上下文已关闭、`activeContexts` 清空及现有任务状态断言。
5. `server-isolation.test.js`：未认证模式 `/api/login-status` 从忙碌 409 改验 404；普通用户释放其他用户任务的 409、管理员释放成功的 200、SIGTERM/SIGKILL、`terminatedJobs` 及 Profile 释放计数断言均移除，改验普通用户和管理员请求两个旧接口一律 404、没有进程信号、运行中任务不受影响。
6. 同文件：删除普通用户释放自身任务成功且 `terminatedJobs` 包含任务 ID 的断言，改验 404、任务继续运行且没有进程信号；任务正常结束后的归属和审计断言保留。
