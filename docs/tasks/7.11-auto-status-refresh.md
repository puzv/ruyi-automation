# 7.11 自动推进完成后刷新工作区状态

## 目标

自动推进在任务成功后接管后续检查并提交下一步任务时，操作面板应立即重新读取工作区状态，避免待办数量和“工作区状态”继续显示任务完成前的旧数据。

## 范围

- 修改 `apps/web/src/views/WorkbenchView.vue`：自动推进立即检查完成后再次刷新工作区状态；
- 补充前端任务轮询测试，验证自动推进分支会重新请求 `/api/status`；
- 不启动浏览器，不读取或修改登录态、上传数据和环境文件。

## 验收

- 自动推进分支在调用 `/api/auto-advance/check` 后重新读取工作区状态；
- `npm test` 通过。
